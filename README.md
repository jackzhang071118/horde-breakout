# Horde Breakout

A lane-runner zombie shooter that runs in the browser. Drag left and right; your squad fires automatically.

- Every bullet that hits a `+` / `−` gate changes it by exactly 1. `×` and `÷` gates can't be shot.
- Blow up barrels to upgrade weapons, pick up allies and drones, and beat the Zombie King at the end of each level.
- Levels are randomly generated on every run.

Play: https://jackzhang071118.github.io/horde-breakout/

Single file (`index.html`), built with Three.js loaded from a CDN. To run locally: `python3 -m http.server 8765` and open http://localhost:8765/.
